# docs / GitHub Pages について

このフォルダは **GitHub Pages** でプライバシーポリシーを **HTTPS の URL** として公開するためのものです。

## ファイルの同期（重要）

- 本文はリポジトリ直下の **`PRIVACY_POLICY_JA.md`** / **`PRIVACY_POLICY_EN.md`** と**同じ内容**にしてください。
- ポリシーを直したときは **両方の場所**（ルートと `docs/`）を更新するか、どちらか一方を正としてコピーしてください。

## 公開後の URL の例

`https://あなたのユーザー名.github.io/リポジトリ名/`

- 日本語: `.../privacy-ja.html`
- 英語: `.../privacy-en.html`

手順の説明は、リポジトリのメンテナ用ドキュメントまたはチャット履歴を参照してください。
